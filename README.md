Java Practice

This repository contains Java practice projects focused on ArrayList and Multithreading.

Projects

StudentManagementSystem

A simple student management system using ArrayList.

Topics covered:

* ArrayList
* add()
* contains()
* remove()
* set()
* size()
* Enhanced for loop

The program adds students, checks whether a student exists, removes and updates students, and prints the current student list.

ThreatExercise

A simple multithreading exercise using Runnable.

Topics covered:

* Runnable
* Thread
* start()
* join()
* setName()
* Thread.currentThread().getName()

Two worker threads run the same task concurrently and print their task numbers. join() is used to wait until both threads finish.

Technologies

* Java
* ArrayList
* Runnable
* Multithreading
